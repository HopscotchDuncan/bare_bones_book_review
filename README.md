# Bare Bones Book Review
###### Created by Robert Duncan for DSCI D532

This is a basic book review frontend for my database project. There are three tables: books, reviews, genres; and you can view, update, edit, and delete every row.

To recreate the database, create a sqlite db file named `final_project_db.db` within the cloned directory and run the sql_dump file located within the project.

Then to run the website, install python and flask, then set up a virtual environment and run this command: `flask --app webpage run` within the cloned directory.

All resources are cited in my submission on canvas :)
